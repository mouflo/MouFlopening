🎞️ TheMovieDB

Sert à retrouver les titres originaux et les identifiants des films et séries (clé « API » de 32 caractères, ou « jeton d'accès » qui commence par eyJ).

🔊 Volume des thèmes

Chaque thème est ramené au même niveau (mesure ReplayGain / MP3Gain). 89 dB est la référence habituelle ; plus le nombre est élevé, plus les thèmes sonnent fort.
S'applique aux nouveaux thèmes (lot, choix à la main, lien ou fichier), jamais à un thème coupé avec l'éditeur ✂️.

📁 Dossiers

Le dossier qui contient tes médiathèques : chaque sous-dossier est proposé ci-dessous. Coche ceux à utiliser et indique ce qu'ils contiennent. Tu peux aussi ajouter des dossiers situés ailleurs. L'appli redémarre après l'enregistrement (quelques secondes).

🍪 Cookies YouTube (facultatif)

Aide l'appli quand YouTube refuse un téléchargement (« connexion demandée », « vidéo non disponible depuis le serveur »). Ne contourne pas les blocages pour droits d'auteur. Utilise de préférence un compte YouTube secondaire, pas ton compte principal : YouTube peut restreindre un compte utilisé par un robot.
Comment obtenir le fichier ?
  1. Dans ton navigateur (Chrome ou Firefox), connecte-toi à youtube.com avec le compte voulu.
  2. Installe une extension d'export de cookies, par exemple « Get cookies.txt LOCALLY ».
  3. Sur la page youtube.com, clique sur l'extension et exporte au format Netscape (fichier cookies.txt).
  4. Ouvre le fichier avec un éditeur de texte, copie tout et colle-le ci-dessous.

🌙 Lot de nuit & Telegram

Chaque nuit, l'appli cherche les thèmes manquants de tous les onglets (mêmes règles que le lot manuel), puis t'envoie un compte rendu sur Telegram s'il y a du nouveau.
Dans ton groupe Telegram, ouvre le sujet de MouFlopening, fais un appui long sur un message → « Copier le lien », colle-le ici : le groupe et le numéro du sujet se remplissent. Le bot doit être membre du groupe.
Détection automatique : écris « bonjour » dans le sujet puis appuie sur le bouton (impossible si le bot sert déjà à une autre application comme Jeedom : utilise alors le lien).
